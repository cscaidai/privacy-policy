01

Scope of This Privacy Policy

This Privacy Policy describes how information is accessed, processed, and handled when users install or interact with the RewriteDeck browser extension.

RewriteDeck is a text rewriting utility that displays a page-side palette containing multiple stylistic rewrite versions of text selected by the user.

Users activate the extension through a right-click context-menu action and can choose a preferred rewrite to apply directly on the current page.

This Privacy Policy applies to RewriteDeck itself and does not govern unrelated websites, browser vendors, operating systems, or independent third-party services.

02

RewriteDeck's Single Purpose

RewriteDeck has a focused purpose: helping users quickly rephrase selected text into alternative stylistic versions without requiring them to leave the current page.

Features reasonably related to this purpose include:

  • Detecting text deliberately selected by the user;
  • Providing a right-click RewriteDeck command;
  • Displaying multiple stylistic rewrite options;
  • Allowing the user to review available versions;
  • Applying a rewrite selected by the user;
  • Replacing or updating the relevant text on the active page; and
  • Displaying the page-side rewrite interface.
03

Selected Text

RewriteDeck accesses text only in connection with a deliberate user-initiated rewrite action.

A typical interaction may involve the user selecting a word, sentence, paragraph, or other text and choosing RewriteDeck from the browser's context menu.

The selected text is then used as the source material for generating or presenting stylistic rewrite alternatives.

Purpose of selected-text processing

Selected text is processed for the purpose of providing the rewrite options requested by the user and applying the selected result.

04

What Text May Be Processed

RewriteDeck does not independently decide which text should be rewritten. The user selects the text that they want the extension to process.

Depending on the page and user action, selected content could technically contain:

  • Ordinary written sentences;
  • Draft text;
  • Descriptions;
  • Notes;
  • Form text;
  • Editorial content;
  • Public webpage text; or
  • Other text deliberately selected by the user.
Avoid selecting sensitive information

Users should not submit passwords, authentication codes, financial credentials, private keys, government identification numbers, or other sensitive information for rewriting unless such processing is appropriate and necessary.

05

Rewrite Options

RewriteDeck may offer multiple stylistic alternatives for a selected piece of text.

These alternatives may differ in wording, tone, structure, brevity, clarity, or other stylistic characteristics supported by the extension.

Rewrite options are presented so that the user can decide which, if any, should be applied.

06

Applying a Rewrite

RewriteDeck may modify text on the currently active page after the user selects a rewrite option.

This modification occurs as part of the extension's disclosed functionality and follows a user action.

The extension does not need to modify unrelated page content merely to provide the selected rewrite.

07

Browser Permissions

RewriteDeck requests browser permissions necessary to provide its context-menu and page-side rewriting functionality.

contextMenus Used to create a right-click RewriteDeck option so users can deliberately initiate the extension.
activeTab Used to obtain temporary access to the active page after the user invokes the extension.
scripting Used to run code necessary to display or apply the chosen rewrite on the current tab after user interaction.
08

contextMenus Permission

RewriteDeck uses the contextMenus permission to add a command to the browser's right-click menu.

This design gives users direct control over when RewriteDeck is activated.

The extension is not intended to automatically rewrite arbitrary page content without the user invoking the relevant command.

09

activeTab Permission

RewriteDeck uses the activeTab permission to access the currently active browser tab after the user has interacted with the extension.

This temporary access allows RewriteDeck to work with the selected text and provide the requested rewrite interface.

The permission is intended to support user-requested functionality rather than continuous access to all browsing activity.

10

scripting Permission

RewriteDeck uses the scripting permission to run the code required to provide the rewrite palette or apply a selected rewrite to the current page.

Script execution occurs in connection with the extension's declared functionality following user interaction or an appropriate extension trigger.

The permission is not intended for unrelated monitoring, surveillance, advertising, or data collection.

11

Processing of Rewrite Requests

When RewriteDeck receives a user-initiated rewrite request, it may process information necessary to produce and display the available alternatives.

Relevant functional information may include:

  • The text selected by the user;
  • The location of the selected text on the active page;
  • The requested rewrite action;
  • The generated or available rewrite alternatives;
  • The rewrite selected by the user; and
  • Temporary interface state.

Such processing is limited to supporting the rewriting functionality requested by the user.

12

Temporary Interface State

While RewriteDeck is active, it may temporarily maintain information needed to display the rewrite palette and respond to user actions.

This may include the currently selected text, available rewrite options, the position of the page-side interface, and the state of the active rewrite session.

Temporary state is used solely to operate the extension interface.

13

Website Content

RewriteDeck may interact with content on the active webpage because its purpose is to rewrite text selected by the user directly on that page.

Such interaction is intended to be limited to what is reasonably necessary to identify selected text, display rewrite choices, and apply the user's chosen result.

RewriteDeck is not designed to create a general archive of every webpage visited by the user.

14

Browsing History

RewriteDeck does not require a complete browsing history to provide its text rewriting functionality.

The extension is not designed to build a historical list of websites visited by users for advertising or profiling purposes.

Access to the current tab is used in connection with a user-initiated rewrite request.

15

Search History

RewriteDeck does not require general search-engine history in order to provide stylistic rewrites.

Search queries on unrelated sites are not used to build advertising profiles or determine the rewrite style presented to the user.

16

Forms and Editable Fields

RewriteDeck may be used on text contained in editable fields when the user deliberately selects that text and invokes the extension.

The extension is not designed to automatically collect all content entered into forms merely because it is installed.

Users should exercise additional care before selecting text from:

  • Login forms;
  • Financial forms;
  • Private communications;
  • Medical forms;
  • Account-management pages; or
  • Other fields containing sensitive information.
17

Keystrokes

RewriteDeck is not designed to operate as a keystroke logger.

The extension does not need to continuously record keyboard activity across unrelated websites in order to provide its core functionality.

Its operation is centered on text deliberately selected by the user.

18

Personal Information

RewriteDeck does not require users to create a dedicated RewriteDeck account in order to access its standard rewriting functionality.

Information such as a user's real name, phone number, home address, government identifier, or payment credentials is not required merely to request a stylistic rewrite.

However, because the user controls what text is selected, selected text could technically contain personal information. Users should avoid selecting sensitive information unless appropriate.

19

Sensitive Personal Information

RewriteDeck does not require sensitive personal information for its ordinary functionality.

Users should avoid deliberately submitting information such as:

  • Passwords;
  • Two-factor authentication codes;
  • Private cryptographic keys;
  • Government identification numbers;
  • Payment card numbers;
  • Banking credentials;
  • Confidential medical information; or
  • Other highly sensitive material.
20

Authentication Information

RewriteDeck does not require passwords, authentication tokens, private keys, security answers, or login credentials to perform its core rewriting function.

Such information should not be selected for stylistic rewriting.

21

Financial Information

RewriteDeck does not need banking information, credit card numbers, payment credentials, or transaction authentication information to provide stylistic rewrite alternatives.

Users should not intentionally submit financial credentials through a rewrite action.

22

Location, Camera, and Microphone

RewriteDeck does not require precise geographic location information to provide text rewrites.

The extension's standard functionality also does not require camera or microphone access.

RewriteDeck is a text-focused extension and does not need to record video, voice, or ambient sound to perform its disclosed purpose.

23

Private Communications

RewriteDeck is not designed to automatically read private communications.

If a user deliberately selects text from an email, message, draft, or other private communication and invokes RewriteDeck, that selected text may be processed as part of the requested rewrite.

Users should consider the sensitivity and confidentiality of text before choosing to rewrite it.

24

Advertising

RewriteDeck is not intended to use selected text for targeted advertising or behavioral advertising.

Browser permissions are requested to provide the disclosed rewriting functionality rather than to construct advertising audiences.

25

Sale of User Information

RewriteDeck does not operate as a service whose purpose is to sell user-selected text or personal information to advertisers or data brokers.

Information accessed through extension functionality is intended to support the rewrite action requested by the user.

26

User Profiling

RewriteDeck is not designed to analyze selected text in order to construct unrelated behavioral, demographic, advertising, credit, employment, or insurance profiles.

Rewrite requests are intended to be processed for text transformation, not unrelated personal profiling.

27

Cross-Site Tracking

RewriteDeck is not designed to track individual users across unrelated websites.

The activeTab permission provides access associated with the user's current interaction rather than requiring permanent access to all browsing activity.

28

Cookies

RewriteDeck does not require advertising cookies to provide its core rewriting functionality.

Websites independently visited by users may use their own cookies, analytics technologies, and tracking systems. Those technologies are controlled by the respective websites.

29

Analytics

RewriteDeck does not require selected text to be used for behavioral advertising analytics.

If the extension's technical or diagnostic practices materially change in a future version, this Privacy Policy may be revised to reflect the applicable processing.

30

Data Minimization

RewriteDeck is designed around the principle that browser access should be limited to what is reasonably necessary to provide the extension's declared purpose.

This includes using user-initiated context-menu activation and temporary active-tab access rather than requiring unrelated permanent browsing access.

31

Purpose Limitation

Information accessed by RewriteDeck is intended to be used only for purposes directly related to providing, maintaining, improving, or securing the extension's disclosed text rewriting functionality.

Browser access is not intended to be repurposed for unrelated surveillance, advertising profiling, credit scoring, data brokerage, or employment screening.

32

Data Retention

RewriteDeck may maintain information temporarily while a rewrite interaction is active so that the selected text, available options, and interface can function correctly.

The extension is not intended to maintain an unrelated permanent browsing archive simply because a user has installed RewriteDeck.

Any future changes to retention practices that materially affect user information should be reflected in an updated version of this policy.

33

Data Security

RewriteDeck is designed to minimize unnecessary browser access and process only information reasonably related to user-requested rewrite functionality.

Limiting access and processing helps reduce unnecessary privacy and security exposure.

However, no browser extension, operating system, browser, device, network, or electronic environment can be guaranteed to be completely secure.

34

No Continuous Background Monitoring

RewriteDeck does not need to continuously inspect all user activity in order to provide its disclosed functionality.

The extension is designed around intentional actions such as selecting text and invoking the RewriteDeck context-menu command.

35

Automated Processing

RewriteDeck may automatically transform selected text into stylistic alternatives.

This automated processing is limited to text rewriting and related interface operations.

RewriteDeck does not use such processing to make automated decisions concerning credit, employment, housing, insurance, legal rights, or similarly significant matters.

36

Accuracy of Rewrites

Stylistic rewrites may alter wording, tone, sentence structure, or emphasis.

Users should review rewrite options before applying them, particularly when working with legal, technical, financial, professional, academic, medical, or otherwise important content.

The user remains responsible for determining whether a rewritten version accurately communicates the intended meaning.

37

Third-Party Websites

RewriteDeck may operate while users are viewing third-party websites, but those websites remain independent from the extension.

This Privacy Policy does not control or describe the independent privacy practices of websites on which RewriteDeck may be used.

38

Browser Platforms

RewriteDeck operates within a browser environment provided by a browser vendor.

Browser vendors may independently process technical information related to installation, updates, extension management, security, or browser operation according to their own privacy policies.

39

Chrome Web Store and Extension Marketplaces

If RewriteDeck is distributed through the Chrome Web Store or another browser extension marketplace, installation and update processes may be handled by that platform.

RewriteDeck is intended to use browser permissions only for purposes directly related to its disclosed rewriting functionality.

40

Children's Privacy

RewriteDeck is a general-purpose writing utility and is not designed specifically for the purpose of collecting personal information from children.

The extension does not require users to provide personal registration information to access its core rewriting functionality.

41

International Users

RewriteDeck may be available to users in multiple countries and regions.

The extension is designed around limited, user-initiated access regardless of where the user is located.

Users remain responsible for using RewriteDeck in accordance with laws applicable in their jurisdiction.

42

User Choice and Control

Users decide which text to select and when RewriteDeck should run.

Users also decide whether to apply any rewrite shown by the extension.

A user can avoid processing text simply by not invoking the RewriteDeck context-menu command.

43

Removing RewriteDeck

Users can disable or uninstall RewriteDeck at any time through their browser's extension management interface.

Once removed, RewriteDeck will no longer be able to perform extension actions within that browser.

44

No Unrelated Commercial Use

Selected text and rewrite choices are not intended to be used to create unrelated marketing databases or behavioral advertising audiences.

RewriteDeck's access is intended to support the text transformation requested by the user.

45

RewriteDeck may evolve over time to improve rewrite styles, interface design, text handling, compatibility, accessibility, reliability, or performance.

Future versions may introduce additional features that remain consistent with the extension's primary text rewriting purpose.

If a future version materially changes how user information is accessed, processed, stored, or shared, this Privacy Policy may be updated accordingly.

If you do not wish to use RewriteDeck under the practices described here, you may discontinue use and uninstall the extension from your browser.
