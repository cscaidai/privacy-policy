01

Overview and Scope

This Privacy Policy explains how information is handled when you install, access, or use the Tangle Loom browser extension.

Tangle Loom provides a popup toolbar interface for building and interacting with node graphs. Users can add nodes by tapping or clicking, connect nodes by dragging between them, observe animated glowing pulses flowing through connections, and reset the graph to begin a new design.

This Privacy Policy applies to functionality provided directly by Tangle Loom. It does not govern independent websites, browser vendors, operating systems, or unrelated online services.

02

Single Purpose

The primary purpose of Tangle Loom is to provide an interactive visual node graph environment inside the browser extension popup.

Functionality reasonably associated with this purpose includes:

  • Creating nodes;
  • Positioning nodes within the graph;
  • Connecting nodes by dragging;
  • Displaying connection lines;
  • Animating glowing pulses through those connections;
  • Updating the visual graph after user interaction;
  • Clearing nodes and connections; and
  • Resetting the interface for a new graph.
03

Personal Information

Tangle Loom does not require personally identifiable information in order to provide its normal graph functionality.

Users are not required to provide information such as:

  • Full name;
  • Email address;
  • Telephone number;
  • Postal address;
  • Government identification information;
  • Payment card information;
  • Bank account information;
  • Passwords; or
  • Authentication credentials.
No dedicated account is necessary.

Users can interact with the standard node graph without creating a Tangle Loom profile or signing into a remote account.

04

Graph Interaction Data

Tangle Loom processes functional graph information so that the extension can display the scene created by the user.

Node coordinates Used to determine where each node appears inside the graph.
Node count Used to maintain the number of currently displayed graph nodes.
Connections Used to determine which nodes are linked together.
Drag interactions Used to create or modify links within the graph.
Animation state Used to display glowing pulses moving through graph connections.
Reset state Used to remove graph elements when the user requests a reset.

This information is application state used for operating the node graph and is not inherently personal information.

05

Node Creation

When a user taps or clicks to add a node, Tangle Loom processes information necessary to create that visual node at the selected location.

Node creation may involve storing temporary values such as the node's identifier, visual position, connection status, or current animation state.

These values exist for the purpose of rendering and maintaining the interactive graph.

06

Connections Between Nodes

Tangle Loom allows users to drag between nodes to create links.

The extension may temporarily maintain information identifying the starting node, ending node, visual path, and relationship between connected nodes.

Connection information is used only to draw and operate the graph created by the user.

07

Glowing Pulse Animation

Tangle Loom displays animated pulses that travel through graph connections.

Animation processing may include information such as:

  • Current pulse position;
  • Animation progress;
  • Connection direction;
  • Timing values;
  • Visual intensity;
  • Active connection paths; and
  • Other rendering values.

These values are generated and processed to display the extension's visual effect.

08

Reset Functionality

The reset control allows users to clear all current nodes and connections from the graph.

When reset is activated, Tangle Loom may remove the current graph state and return the interface to its initial condition.

Reset operations are functional actions and are not used to collect information about the user.

09

Local Processing

Tangle Loom is designed so that its primary graph interactions and animations can be handled within the browser extension environment.

Local processing may include:

  • Creating graphical nodes;
  • Calculating node positions;
  • Detecting drag actions;
  • Creating connections;
  • Rendering connection lines;
  • Animating pulses;
  • Updating the graph state; and
  • Clearing the graph.
Data minimization

Tangle Loom is intended to process only information reasonably necessary to provide its visual node graph functionality.

Temporary graph state exists to allow the extension to respond correctly to user actions.
