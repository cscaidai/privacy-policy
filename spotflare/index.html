Spotflare Browser Extension

Privacy Policy

This policy explains how Spotflare handles information when users dim a webpage and highlight selected text with a warm glowing frame and pulse effect.

Spotflare is a local visual-focus tool. It does not require an account, does not maintain browsing profiles, and does not send selected webpage text or browsing activity to a developer-operated server.

1. Purpose and Scope

This Privacy Policy applies to the Spotflare browser extension and describes how information is handled when the extension is used from the browser toolbar or the right-click context menu.

Spotflare temporarily dims the visible webpage while keeping the user's selected text in focus. The selection is emphasized with a warm glowing frame and pulsing visual treatment so that important content can be reviewed with less distraction.

The extension is not designed as an analytics service, advertising platform, account-based product, cloud storage service, or content collection system.

2. How Spotflare Operates

Spotflare runs only after the user performs a deliberate action. A user may select text and choose the Spotflare command from the right-click menu, or invoke the extension through its toolbar popup.

After activation, Spotflare applies the dimming layer and spotlight frame to the current active tab. The effect is rendered locally in the browser and is limited to the page on which the user triggered it.

Refreshing the page, navigating away, closing the tab, disabling the extension, or removing the effect ends the current visual treatment. Spotflare does not preserve a permanent copy of the page or maintain a history of highlighted selections.

3. Handling of Selected Text

When the user highlights text and activates Spotflare, the extension accesses the selection only to determine the area of the page that should remain visible and receive the glowing frame.

Selected text is processed solely for the immediate visual function requested by the user. Spotflare does not transmit that text to the developer, upload it to an external server, use it to train a model, analyze it for advertising, or combine it with content from other websites.

The extension does not intentionally retain selected text once the effect is no longer active. No searchable archive, selection history, or user-content database is created by Spotflare.

4. Information Spotflare Does Not Collect

Spotflare does not collect personal information and does not require users to submit identifying details. No registration, login, payment information, or user profile is required to use the extension.

The extension does not collect or maintain records of:

  • Names, email addresses, telephone numbers, or account credentials;
  • Browsing history, visited URLs, bookmarks, searches, or open-tab activity;
  • Selected text, webpage content, form entries, passwords, or private messages;
  • IP addresses, device identifiers, precise location, or demographic information;
  • Advertising identifiers, behavioral profiles, telemetry, or usage analytics.

Because these categories of data are not collected, the developer does not maintain a personal-data database associated with Spotflare.

5. Browser Permissions and Their Use

Spotflare requests only the permissions required to provide its visible, user-initiated highlighting feature.

contextMenus

This permission allows Spotflare to add a command to the browser's right-click menu. The command appears so that the user can intentionally apply the spotlight effect to selected text. The extension does not activate merely because the context menu is opened.

activeTab

This permission gives Spotflare temporary access to the currently active tab after the user invokes the extension. It is used only to apply the dimming and spotlight effect to the page the user is viewing.

scripting

This permission allows Spotflare to inject and execute the code that dims the page, preserves the selected area, and displays the glowing pulse frame. It is not used to silently monitor browsing behavior, scrape websites, or intercept credentials.

6. Remote Code and External Processing

Spotflare does not use remote code. The executable code needed to provide the extension's functionality is included in the installed extension package.

The extension does not download additional executable logic from an external server at runtime and does not rely on third-party processing services to create the visual effect.

7. Data Sharing, Sale, and Disclosure

Spotflare does not sell, rent, license, trade, or disclose personal information. It does not share user data with advertisers, analytics companies, data brokers, social networks, or marketing platforms.

Because Spotflare does not collect personal information, there is ordinarily no user data available for disclosure. The browser, the website being viewed, and the extension store remain separate services governed by their own privacy terms.

8. Advertising, Analytics, and Cross-Site Tracking

Spotflare does not display advertising and does not include advertising SDKs, tracking pixels, third-party cookies, session replay tools, fingerprinting scripts, or behavioral analytics.

The extension does not follow users across websites, build interest profiles, or combine activity from different domains. Its operation is limited to the tab where the user explicitly activates the feature.

9. Security and Data Retention

Spotflare minimizes privacy risk by avoiding the collection and transmission of personal information. The extension performs its visual processing locally in the browser and does not create a developer-controlled archive of selections or browsing activity.

No software system can eliminate every possible security risk. However, Spotflare follows a limited-purpose approach by using only the permissions tied to its visible function and by avoiding persistent storage of selected webpage content.

10. Changes to This Privacy Policy

This Privacy Policy may be updated if Spotflare's features, permissions, or information practices change. Any revised version will include an updated effective date and will describe the extension's current behavior.

If a future version introduces data collection, external processing, or additional permissions, this policy will be revised before those practices are represented as part of Spotflare.

11. Contact

Questions, privacy inquiries, or requests for clarification may be sent to the support address listed on Spotflare's official browser-extension store page.
