Chromawave Browser Extension

Privacy Policy

This policy explains how Chromawave handles information when users animate selected text with a rainbow wave, smooth color cycling, and subtle letter movement.

Effective date: July 13, 2026

Chromawave is a local visual-animation tool. It does not require an account, does not build browsing profiles, and does not send selected text or webpage activity to a developer-operated server.

1. Purpose and Scope

This Privacy Policy applies to the Chromawave browser extension and describes how information is handled when users activate the extension through the toolbar popup or the browser's right-click context menu.

Chromawave transforms text selected by the user into a colorful animated wave. The effect cycles through rainbow colors and applies gentle movement to individual letters so the selected content becomes visually expressive without altering the underlying meaning of the page.

The extension is not intended to provide advertising, analytics, account management, cloud storage, content indexing, or cross-site personalization.

2. How Chromawave Operates

Chromawave becomes active only after the user performs a deliberate action. A user may select text and choose the Chromawave command from the context menu, or use the toolbar popup to apply the effect on the current tab.

Once activated, the extension inserts the visual code needed to animate the selected characters. The animation is rendered locally in the browser and is limited to the active page where the user initiated the feature.

Refreshing the page, navigating away, closing the tab, disabling the extension, or removing the effect ends the current animation. Chromawave does not create a permanent copy of the webpage or maintain a history of previously animated text.

3. Handling of Selected Text

When the user selects text and activates Chromawave, the extension accesses that selection only to identify which visible characters should receive the rainbow wave animation.

The selected content is processed solely for the immediate visual function requested by the user. Chromawave does not transmit selected text to the developer, upload it to an external server, analyze it for advertising, or combine it with content from other websites.

Chromawave does not intentionally retain the selected text after the animation is no longer active. No searchable archive, selection history, or user-content database is created by the extension.

4. Information Chromawave Does Not Collect

Chromawave does not collect personal information and does not require registration, login credentials, payment details, or a user profile.

The extension does not collect or maintain records of:

  • Names, email addresses, telephone numbers, or account credentials;
  • Browsing history, visited URLs, bookmarks, search activity, or open tabs;
  • Selected text, webpage content, form entries, passwords, or private messages;
  • IP addresses, device identifiers, precise location, or demographic information;
  • Advertising identifiers, behavioral profiles, telemetry, or usage analytics.

Because these categories of data are not collected, the developer does not maintain a personal-data database associated with Chromawave.

5. Browser Permissions and Their Use

Chromawave requests only the permissions needed to provide its visible, user-initiated text-animation feature.

contextMenus

This permission allows Chromawave to add a command to the browser's right-click menu. The command gives users a direct way to apply the animation to selected text. Opening the context menu alone does not cause the extension to run or collect information.

activeTab

This permission gives Chromawave temporary access to the currently active tab after the user invokes the extension. It is used only to apply the rainbow wave effect to the page the user is viewing.

scripting

This permission allows Chromawave to inject and execute the code that cycles colors and shifts letters within the selected text. It is not used to silently monitor browsing behavior, scrape websites, or intercept credentials.

6. Remote Code and External Processing

Chromawave does not use remote code. The executable code required for the extension's animation is included in the installed extension package.

The extension does not download additional executable logic at runtime and does not depend on third-party processing services to render the rainbow wave effect.

7. Data Sharing, Sale, and Disclosure

Chromawave does not sell, rent, license, trade, or disclose personal information. It does not share user data with advertisers, analytics companies, data brokers, social networks, or marketing platforms.

Because Chromawave does not collect personal information, there is ordinarily no user data available for disclosure. The browser, the current website, and the extension marketplace remain separate services governed by their own privacy terms.

8. Advertising, Analytics, and Cross-Site Tracking

Chromawave does not display advertising and does not include advertising SDKs, tracking pixels, third-party cookies, fingerprinting scripts, session replay tools, or behavioral analytics.

The extension does not follow users across websites, create interest profiles, or combine activity from different domains. Its operation is limited to the active tab where the user explicitly triggers the feature.

9. Security and Data Retention

Chromawave minimizes privacy risk by avoiding the collection and transmission of personal information. The extension performs its animation locally in the browser and does not create a developer-controlled archive of selections or browsing activity.

No software system can remove every possible security risk. However, Chromawave follows a limited-purpose design by using only permissions connected to its visible function and by avoiding persistent storage of selected webpage content.

10. Changes to This Privacy Policy

This Privacy Policy may be updated if Chromawave's features, permissions, or information practices change. Any revised version will include an updated effective date and will describe the extension's current behavior.

If a future version introduces data collection, external processing, or additional permissions, this policy will be revised accordingly before those practices are represented as part of Chromawave.

11. Contact

Questions, privacy inquiries, or requests for clarification may be sent to the support address listed on Chromawave's official browser-extension store page.
