GlowStage Browser Extension

Privacy Policy

This policy describes how GlowStage handles information when users activate the extension to dim a webpage and spotlight selected text with a pulsing visual halo.

Effective date: July 13, 2026

GlowStage is designed as a local visual utility. It does not require an account, does not operate an advertising network, and does not maintain a database of users, browsing histories, or selected webpage content.

1. Purpose and Scope

This Privacy Policy applies to the GlowStage browser extension and explains the extension's approach to information handling. It covers the actions performed when a user activates GlowStage from the browser toolbar or from the extension's right-click context menu.

The purpose of GlowStage is limited to changing the presentation of the current webpage. It dims the surrounding page and places a glowing, rhythmically pulsing halo around text selected by the user. The extension is not intended to provide analytics, advertising, account management, cloud synchronization, or data storage services.

2. How GlowStage Operates

GlowStage runs only after a user performs a deliberate action, such as choosing its context-menu command or opening the toolbar popup and activating the feature. Once invoked, the extension executes the code needed to apply the visual effect to the active tab.

The effect is rendered inside the user's browser. GlowStage does not need to send the webpage, the selected text, or the user's browsing activity to a developer-owned server in order to perform its function.

Closing the page, navigating away, refreshing the tab, or removing the applied effect ends the current presentation. GlowStage does not create a permanent copy of the page or preserve a record of what was highlighted.

3. Treatment of Selected Text

When a user highlights text and invokes GlowStage, the extension reads the selection only to determine which visible content should receive the spotlight effect. This processing occurs for the immediate purpose requested by the user.

GlowStage does not transmit selected text to the developer, use it to build a profile, analyze it for advertising, or combine it with information from other websites. The extension does not intentionally retain selected text after the requested effect has been applied.

Users should nevertheless avoid selecting confidential information on untrusted pages, because the webpage itself and other software installed in the browser may have their own data practices that are outside GlowStage's control.

4. Information GlowStage Does Not Collect

GlowStage does not collect personal information from users. It does not request a name, email address, telephone number, account credential, or payment detail. It also does not create a user account or assign a persistent advertising identity.

The extension does not collect or maintain records of:

  • Browsing history, visited URLs, bookmarks, or search activity;
  • Selected text, webpage content, form entries, passwords, or private messages;
  • IP addresses, precise location, device identifiers, or demographic attributes;
  • Advertising identifiers, behavioral profiles, or cross-site activity;
  • Usage analytics, heatmaps, session recordings, or telemetry reports.

Because GlowStage does not collect these categories of information, the developer does not maintain a personal-data database associated with the extension.

5. Browser Permissions and Their Use

GlowStage requests a limited set of browser permissions. Each permission supports a visible feature initiated by the user and is not used for unrelated monitoring.

contextMenus

This permission allows GlowStage to place an action in the browser's right-click menu. The action is shown so that a user can intentionally apply the spotlight effect to selected text. Merely displaying the menu entry does not cause GlowStage to collect or transmit information.

activeTab

This permission provides temporary access to the current tab after the user invokes the extension. GlowStage uses that temporary access to identify the selected content and apply the requested visual treatment. It does not provide unrestricted background access to every page the user visits.

scripting

This permission allows GlowStage to inject and execute the code that dims the page and renders the pulsing halo. The script runs only as part of the extension's declared function after user interaction. It is not used to scrape pages, intercept credentials, or silently observe browsing behavior.

GlowStage does not use remote code. The executable logic required for these features is packaged with the installed extension rather than downloaded from an external server at runtime.

6. Data Sharing, Sale, and Disclosure

GlowStage does not sell, rent, license, or trade personal information. It does not share user data with advertisers, data brokers, analytics companies, social networks, or other third parties for commercial purposes.

Since the extension does not collect personal information, there is ordinarily no user data available for disclosure. Information processed by the browser, the website being viewed, or the extension marketplace remains subject to the policies of those separate services.

7. Advertising, Analytics, and Cross-Site Tracking

GlowStage does not display advertising and does not contain advertising SDKs. It does not use tracking pixels, browser fingerprinting, third-party cookies, session replay, audience measurement tools, or behavioral analytics.

The extension does not follow users across websites, combine activity from different domains, or create profiles for personalized marketing. Its operation is limited to the tab and content on which the user directly activates the feature.

8. Security and Data Retention

GlowStage reduces privacy risk by avoiding the collection and transmission of personal information. The extension's visual processing is performed locally in the browser, and no developer-operated archive of selected text or browsing activity is created.

No technical system can eliminate every possible risk. However, GlowStage follows a limited-purpose design: it requests only permissions connected to its visible function and does not retain user content for later use.

9. Children's Privacy

GlowStage does not knowingly collect personal information from children. The extension does not offer account registration, social communication, targeted advertising, or features intended to gather information from users of any age.

10. Changes to This Policy

This Privacy Policy may be revised if GlowStage's features, permissions, or information practices change. Any updated version will include a revised effective date and will describe the extension's current behavior.

A future version that introduces data collection, external processing, or additional permissions would require corresponding updates to this policy before those practices are represented as part of GlowStage.

11. Contact

Questions, privacy inquiries, or requests for clarification may be sent to the support address listed on GlowStage's official browser-extension store page.
