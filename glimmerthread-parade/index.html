01

Scope of This Privacy Policy

This Privacy Policy explains how information is accessed, processed, stored, and handled when you install or use the glimmerthread parade browser extension.

glimmerthread parade creates an ambient visual effect by displaying three glowing ribbons that weave horizontally across the current webpage with gentle color transitions and adjustable movement speed.

Users can activate and customize the effect through the extension's toolbar popup.

This Privacy Policy applies to functionality provided directly by glimmerthread parade. It does not govern unrelated websites, browser vendors, operating systems, or independent third-party services.

02

Single Purpose

The primary purpose of glimmerthread parade is to provide a customizable ambient visual effect on the webpage selected by the user.

Functionality reasonably related to this purpose may include:

  • Displaying three glowing ribbon elements;
  • Animating ribbons horizontally across the viewport;
  • Applying gradual color transitions;
  • Adjusting ribbon movement speed;
  • Enabling or disabling the visual effect;
  • Applying the selected effect to the current active tab;
  • Removing the effect when requested; and
  • Remembering customization preferences locally.
03

No Account Required

glimmerthread parade does not require users to create a dedicated account in order to use its standard visual functionality.

Users are not required to register a username, password, personal profile, or email address merely to activate or customize the ribbon effect.

04

Browser Permissions

glimmerthread parade requests browser permissions that directly support its disclosed visual functionality.

activeTab Provides temporary access to the currently active tab when the user invokes the extension.
scripting Allows the extension to execute the code necessary to display or update the glowing ribbon effect.
storage Allows customization preferences to be stored locally in the user's browser.
05

activeTab Permission

glimmerthread parade uses the activeTab permission only when the user invokes the extension on the currently active tab.

This allows the extension to apply its declared ambient effect to the page the user is viewing.

The permission is intended to provide temporary, user-triggered access rather than permanent access to every website visited by the user.

User-initiated access

The active page is accessed in connection with an intentional extension action initiated by the user.

06

scripting Permission

glimmerthread parade uses the scripting permission to execute code required to create and control its declared visual effect.

Script execution may be used to:

  • Create the three ribbon elements;
  • Add visual styles;
  • Animate ribbon movement;
  • Update colors;
  • Adjust animation speed;
  • Apply customization changes; or
  • Remove the visual effect.

This permission is intended to support the extension's user-facing functionality rather than unrelated monitoring.

07

storage Permission

glimmerthread parade uses the storage permission to save extension settings locally in the user's browser.

Local storage allows the extension to remember customization choices so that users can maintain a consistent visual experience.

Stored settings may include values such as:

Effect state Whether the glowing ribbon effect is enabled or disabled.
Animation speed The movement speed selected by the user.
Visual preferences Settings related to how the ribbon animation is displayed.
Configuration values Other non-sensitive preferences required to restore the selected effect.
08

Local Storage of Preferences

Extension preferences are stored locally in the user's browser for convenience.

Local settings are intended only to support glimmerthread parade's functionality and are not intended to create advertising or behavioral profiles.

Depending on browser behavior, these settings may remain until they are changed, cleared, or removed by the user.

09

Visual Effect Data

glimmerthread parade processes functional values needed to display the animated ribbons.

These may include:

  • Ribbon positions;
  • Animation timing;
  • Movement speed;
  • Transition progress;
  • Color states;
  • Opacity values;
  • Current animation state; and
  • Other visual rendering parameters.

These values are functional application data and are not inherently personally identifiable information.

10

Color Transitions

glimmerthread parade uses gradual color transitions to create the ambient glowing effect described in its extension listing.

Color values and transition states are generated or processed solely for visual rendering purposes.

Color changes are not intended to identify individual users or infer personal characteristics.

11

Animation Speed

Users may adjust the speed at which the glowing ribbons move across the viewport.

The selected speed is treated as a functional extension preference.

It may be stored locally so that the preferred animation speed can be restored during future use.

12

Interaction With the Current Webpage

glimmerthread parade interacts with the active webpage in order to display its glowing ribbon effect across the viewport.

Such interaction is intended to be limited to what is reasonably necessary to create, update, animate, and remove the extension's visual elements.

The extension's purpose does not require building a general archive of webpage content.
