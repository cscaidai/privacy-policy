Privacy summary

A focused mechanical simulation

Gearspire processes the numerical and visual state needed to render a vertical gear tower and respond to real-time tuning controls. Its standard functionality does not require users to create a personal Gearspire account.

01

Scope of This Privacy Policy

This Privacy Policy explains how information is handled when you install, access, or use the Gearspire browser extension.

Gearspire provides a toolbar-popup simulation in which users can tune the sizes and rotational speeds of gears arranged within a vertical tower.

Changes are reflected in real time so users can experiment with different rhythmic spinning patterns and visual relationships between gears.

This policy applies to functionality provided directly by Gearspire and does not govern unrelated websites, browser vendors, operating systems, or independent services.

02

Single Purpose

Gearspire has a focused single purpose: providing an interactive gear simulation that allows users to modify gear sizes and speeds and observe the resulting visual motion.

Features reasonably related to this purpose may include:

  • Displaying a vertical gear tower;
  • Rendering multiple gears;
  • Adjusting gear dimensions;
  • Adjusting rotational speeds;
  • Changing movement in real time;
  • Updating gear relationships;
  • Displaying rhythmic spinning motion;
  • Resetting simulation values; and
  • Other controls related directly to the gear simulation.
03

No Account Required

Gearspire does not require users to create a dedicated account in order to access its standard simulation functionality.

Users do not need to register a username, password, profile, email address, or other personal identity information merely to adjust gears and observe the resulting animation.

04

Gear Simulation Data

Gearspire processes functional information necessary to display and operate the simulated gear system.

Gear size Determines the visual dimensions of a gear in the tower.
Rotational speed Determines how quickly a simulated gear rotates.
Rotation state Used to maintain the current visual angle and animation.
Gear position Determines placement within the vertical tower interface.

These values are simulation parameters and are not inherently personally identifiable information.

05

Gear Size Controls

Gearspire allows users to modify the size of simulated gears within the vertical tower.

A gear-size value may affect the appearance of the gear, its relationship with nearby gears, spacing, rotation, or other visual behavior supported by the simulation.

Gear-size values are used solely to provide the interactive functionality requested by the user.

06

Speed Controls

Users may adjust rotational speed values through Gearspire's real-time controls.

Speed values determine how quickly the corresponding simulated gear rotates.

They may also influence the overall visual rhythm produced by the gear tower.

07

Real-Time Updates

Gearspire updates the simulation when users change available controls.

Real-time processing may include:

  • Reading the selected gear size;
  • Reading the selected speed;
  • Updating gear dimensions;
  • Updating rotational velocity;
  • Recalculating visual relationships;
  • Rendering animation frames; and
  • Displaying the resulting motion.
08

Vertical Tower Layout

Gearspire displays gears in a vertical tower arrangement.

The extension may maintain information about gear order, spacing, positions, sizes, and related visual geometry so that the tower can be rendered correctly.

These values relate to the internal simulation interface rather than the user's physical location or identity.

09

Rhythmic Spin Patterns

Different gear sizes and speed combinations may produce different visual rhythms.

Gearspire may calculate animation timing, rotation direction, rotational progression, or other values required to create the resulting spinning pattern.

These calculations are used only for the extension's simulation.

10

Functional Processing

Gearspire may process information necessary to maintain the current simulation state.

Such information may include:

  • Number of gears;
  • Gear dimensions;
  • Gear order;
  • Rotational speed;
  • Rotation direction;
  • Current rotation angle;
  • Animation timing;
  • Control values;
  • Reset state; and
  • Other simulation parameters.
11

Toolbar Popup Interface

Gearspire is designed to provide its primary functionality through a browser toolbar popup.

The popup contains the controls and visual simulation needed to tune the gear tower.

Users can access the simulation without navigating away from the webpage currently open in the browser.

12

Temporary Simulation State

While Gearspire is running, the extension may temporarily maintain the information needed to display the current gear configuration.

This may include gear sizes, speed values, rotation angles, animation timing, tower arrangement, and other visual state.

Temporary state is functional information used to operate the simulation.
